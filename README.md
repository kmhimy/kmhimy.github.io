# 科研工作台 V9 — 全局搜索 + 今日科研进展 + 科研笔记模板

V9 按科研实际使用流程继续完善三件事。

## 1. 全局搜索

顶部新增“搜索”，也可以使用：

`Ctrl + K`

可同时搜索：

- 科研项目名称、说明、项目总结
- 任务标题
- 任务科研笔记
- 每一条任务工作记录
- 科研日志

支持中文、英文和公式关键词。

例如：

- `XY cancellation`
- `rank-two`
- `J_XY`
- `审稿意见`

快捷键：

- `↑ / ↓`：选择结果
- `Enter`：打开
- `Esc`：关闭
- `Ctrl + K`：打开 / 关闭搜索

搜索结果可以直接跳转到项目、任务、具体工作记录或科研日志。

---

## 2. 首页“今日科研进展”

首页现在不再只看“完成了几个任务”。

新增“今日科研进展”，自动汇总今天写下的所有 Task Work Log。

因此即使某个任务要连续做五天才完成，每一天真正做过的事情仍然会被记录。

例如：

```text
10:32  暗空间
       检查三节点 logistic invariant
       得到……

14:16  多模波导
       重算三模 XY cancellation
       发现……
```

这使：

“完成任务” 和 “今天真正推进了什么”

成为两个不同指标。

## 3. 科研笔记模板

新建任务时增加“科研笔记模板”。

可选：

- 空白
- 理论推导
- 数值计算
- 论文修改
- 文献阅读
- Figure 制作
- 审稿回复

例如“理论推导”会自动生成：

```text
# 研究目标

## 模型与假设

## 推导

\[
H =
\]

## 一致性检查

## 当前结论

## 未解决问题

## 下一步
```

任务已经创建以后，在 Overleaf 风格科研笔记顶部仍然可以“套用模板”。

如果已有内容，系统会先确认，避免误覆盖。

## 其他改进

- 离开任务详情时会先强制保存科研笔记，降低快速返回造成的未保存风险。
- 新增/删除工作记录后，首页“今日科研进展”会立即刷新。
- 搜索工作记录时可以直接滚动到对应历史记录。

## 数据兼容

无需修改 Supabase 表。
无需重新运行 SQL。

V8 的项目、任务、归档、科研笔记、LaTeX、工作记录、日历、外观设置全部兼容。
