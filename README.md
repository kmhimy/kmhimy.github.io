# 科研工作台 V7.1 — 可折叠侧边栏 + 可拖动 Overleaf 分栏

## 1. 左侧侧边栏可以折叠

侧边栏顶部新增折叠按钮。

折叠以后：
- 工作区横向空间明显增加
- 只保留 R 标记和“今 / 项 / 志 / 周”快捷入口
- 鼠标悬停会显示对应名称
- 登录状态保留为一个同步状态点

再次点击即可展开。

折叠状态会自动记住。

手机端不启用侧边栏折叠，保持原来的横向导航。

## 2. 源码 / 实时预览可自由拖动

在“分栏”模式下：

- 鼠标拖动中间分隔线，可以自由改变左右宽度
- 左侧最小约 28%
- 左侧最大约 78%
- 默认约 58% / 42%
- 双击分隔线恢复 58% / 42%
- 键盘聚焦分隔线后：
  - ← / →：每次调整 2%
  - Home：28%
  - End：78%

你最后使用的比例会自动记住。

“仅编辑”和“仅预览”模式下不显示拖动条。
