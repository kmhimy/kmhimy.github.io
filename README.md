# 科研工作台 V11

V11 的核心目标：把 V10 的功能真正连接成一个完整的科研工作流。

## 新增

### 研究总览（Project Dashboard）

快捷键 `9`。

选择项目后集中查看：

- 任务数量与完成率
- 科研日志
- Work Log
- 科研资源
- 当前任务
- 研究总结
- 双向任务网络
- 最近科研活动

### 项目研究总结

每个项目增加：

- 研究问题
- 核心假设
- 主要结果
- 当前困难
- 下一步

### 双向任务网络

项目总览会同时显示：

- 我设置的关系
- 被其他任务关联

例如：

```text
核心推导
  ├─ 依赖于 → bright-space Hamiltonian
  └─ 后续 → numerical verification

被关联
  ← Appendix proof
```

### 项目时间轴联动

研究总览显示当前项目最近活动。点击记录可以直接进入对应任务、Work Log 或科研日志。

“查看完整时间轴”会进入 V10 的科研时间轴并自动按当前项目筛选。

## 兼容

V11 自动为旧项目补充：

```text
researchSummary
```

不需要修改 Supabase SQL。

V10 的任务关联、资源、时间轴、回收站、LaTeX、日历、外观和云同步全部保留。

如果部署后没有看到 V11，请 `Ctrl + F5` 强制刷新。


## 任务详情导出增强

任务详情现在支持 PDF、LaTeX (.tex)、Markdown (.md) 和纯文本 (.txt)。PDF 使用浏览器本地打印为 PDF，公式使用当前 KaTeX 渲染结果，不上传第三方服务。


## V12 — 今天：科研指挥中心

“今天”不再只是待办列表，而是整个系统的默认科研入口。

### 每天打开后回答三个问题

1. 今天最重要的三件科研工作是什么？
2. 昨天做到哪里？
3. 今天从哪里继续？

### 新增

- 今日三件事：从真实任务中选择，最多 3 项
- 昨日连续性：自动读取昨天的 Work Log 与完成任务
- 今日续接：优先显示今日重点和最近有 Work Log 的未完成任务
- 今日工作台：科研 / 写作 / 事务筛选
- 今日推进证据：完成任务与 Work Log 自动汇总
- 日终小结：保存一句“今天做到哪里，明天从哪里继续”
- 第二天首页自动显示昨天留下的小结
- 专注模式：只保留“今日三件事”，右上角始终保留“退出专注”，Esc 也可退出

V12 使用现有本地 / Supabase state 数据结构，不需要新增 SQL 表。


## V12.1 初始化修复

修复 V12 首次加载时出现：

`Cannot set properties of null (setting 'value')`

原因是旧版 Today 兼容 DOM 在 `app.js` 执行之后才被浏览器解析。

V12.1：
- 将兼容 DOM 移至 app.js 之前
- 对旧 quickNote 初始化增加空值保护
- 静态资源版本统一升级为 12.1.0，避免浏览器继续使用旧缓存


## V12.2 — Today 架构清理

本版不再使用隐藏 DOM 兼容旧 Today 页面。

- 删除 V11 Today 的旧 DOM 引用
- 删除旧 `renderTodayLegacy`
- 删除旧 priority / task / done Today 渲染器
- 删除旧 quickNote 与旧 Today 筛选事件
- V12 `renderToday()` 成为唯一 Today 页面渲染器
- 对 `getElementById` 引用与实际 HTML ID 做静态一致性检查
- JavaScript 通过 Node 语法检查
- 静态资源缓存版本升级至 12.2.0

这解决了登录页初始化阶段因旧 Today DOM 不存在而出现的 null 属性错误。


## V12.3 — 可调字体大小

外观页新增全局字体大小：85%–125%，步进 5%，并提供 90/100/110/120% 快捷档位。设置随现有 state/Supabase 同步。科研笔记编辑器和 KaTeX 数学公式保持独立比例。


## V12.4 — 默认字号层级统一

V12.4 不增加新功能，专门整理视觉层级。

- 100% 现在作为推荐默认字号
- Today 页去除重复的超大标题层级
- 页面主标题约 42px
- 模块标题约 24–27px
- 任务/正文约 14–16px
- 辅助信息约 11–13px
- 导航与按钮约 14–15px
- 小屏幕主标题自动降至约 34px
- V12.3 的 85%–125% 用户缩放继续保留


## V12.5 — Today 单一 Header

- 清理 Today 页旧版重复标题区域
- 顶部只保留一套日期 + “今天”标题
- 顶部只保留一套“昨天回顾 / 专注模式 / 添加任务”操作
- 减少顶部垂直占用
- 保留 V12.4 字号层级和 V12.3 的 85%–125% 自定义缩放


## V12.6 — 移除顶部全局“今日”

V12.5 中仍出现的超大“今日”来自应用级全局页面标题，而不是 `#view-today` 内部。

V12.6：
- Today 激活时隐藏应用级全局页面标题
- 其他页面仍保留各自页面标题
- Today 只保留：日期 → 今天 → 说明
- Today 只保留一套操作按钮
- 初始 body 直接带 Today 状态，减少旧标题闪现


## V12.7 — Today 操作区统一

Today 页顶部现在只有一套操作按钮：

- 搜索
- 昨天回顾
- 专注模式
- 添加任务

Today 激活时，应用级全局 Header 整体隐藏；切换到项目、日志、日历、时间轴等其他页面后，全局 Header 正常恢复。

搜索功能不是删除，而是移动到 Today 自己的 Header 中，并继续复用 Ctrl+K 全局搜索。


## V12.8 — 专注模式布局修复

修复 V12.7 中进入专注模式后：

- 内容被压缩到左侧窄栏
- 右侧出现巨大空白
- Search / Exit Focus 与主体布局脱节

V12.8 专注模式使用独立布局：

- 隐藏侧栏与全局 Header
- Today 居中，最大宽度 1120px
- 顶部只保留 Search + Exit Focus
- “今天最重要的三件事”占满主体宽度
- 不再继承普通页面的 sidebar/grid/margin-left
- 解决 font-scale 的 zoom 与专注模式宽度冲突
- Esc 仍可退出专注


## V12.9 — 日历可读性优化

根据实际日历页面截图提高小字号信息的可读性：
- 星期标题增大并加重
- 日期数字与 “+” 增大
- 日历事件文字适当增大
- “近期截止”中的日期、任务标题、项目/分类信息增大
- 保持“近期截止 / 已逾期”等模块标题原有视觉层级


## V13 — 日历分类颜色与日期标记

- 科研：绿色
- 写作：紫色
- 事务：暖棕色
- 日期格内用小圆点标记当天包含的任务分类
- 同一天包含多种分类时并排显示多个圆点
- 日历中的任务标签与分类颜色一致
- 日期右上角 `+` 根据当天已有任务分类着色
- 同一天有多类任务时，`+` 使用多色渐变
- 日历顶部提供分类颜色图例

颜色表示任务分类，不表示任务优先级。


## V13.1 — Today 推进记录可单独移除

“任务完成”和“是否保留在今天推进记录中”现在分开处理。

- 完成任务 / 新建 Work Log 仍会自动进入“今天推进了什么”
- 每条记录右侧新增 `×`
- 点击 `×` 只从今日推进汇总中移除
- 不删除任务
- 不撤销完成状态
- 不删除 Work Log
- “恢复隐藏”可以恢复当天所有被移除的推进记录

隐藏状态按日期保存到 `state.daily[date].hiddenProgress`，可随现有云同步保存。


## V13.2 — 事务与科研分离 + 遗留 DOM 修复

### 事务独立目录
左侧新增“事务”：
- 不归属科研项目
- 不进入研究总览
- 不进入科研时间轴
- 不参与科研项目任务统计
- 仍可在“今天”和“日历”中出现，作为每日总体安排的一部分
- 选择“事务”分类时项目选择自动清空并禁用

事务页包含待办、今天截止、逾期、已完成四类统计与筛选。

### 左下角异常输入框
彻底删除旧版本遗留的 `quickNote` / Today compatibility DOM，不再依赖隐藏兼容元素。


## V14 — 稳定性与一致性优化

以实际部署的 V13.2 为唯一基线，不新增业务模块。

- 设置页增加完整 JSON 数据备份
- 保存前强制执行“事务不属于科研项目”的数据不变量
- 删除任务统一按“移到回收站”表达
- 加强键盘焦点、触屏、长标题和窄屏布局
- 保留事务与科研隔离，以及 Today / 日历总体汇总
- 通过 JavaScript 语法、DOM ID 和旧 quickNote 遗留检查


## V14.1 — 任务名称可修改

- 任务详情标题右侧增加“编辑名称”
- 点击后弹出独立的任务名称编辑框
- 自动选中原名称，便于快速修改
- 保存后立即刷新 Today、日历、项目、事务、搜索等所有引用该任务名称的位置
- 只修改任务 title，不改变项目归属、分类、完成状态、Work Log 或科研笔记
