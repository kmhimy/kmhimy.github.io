# 科研工作台 V5 — 项目归档与详情页

V5 在 V4 的登录与 Supabase 云同步基础上，补全科研项目生命周期。

## 新功能

- 项目可以归档、恢复
- 已归档项目进入独立归档区
- 归档后任务、科研日志、项目总结全部保留
- 已归档项目不再出现在新建任务/日志的项目选择列表
- 点击项目卡片进入项目详情页
- 详情页显示状态、创建/归档时间、任务完成率、全部任务、科研日志
- 新增项目总结，并自动保存、自动云同步
- 删除项目现在明确标记为永久删除；完成项目优先使用归档

## 数据兼容

不需要修改 Supabase 数据表，也不需要重新运行 SQL。V5 会自动给旧项目补齐 `archivedAt` 和 `summary` 字段。V4 的项目、任务、日志、随手记和登录状态继续保留。
