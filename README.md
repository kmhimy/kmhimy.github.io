# 科研工作台 V10

本版新增：

1. 任务关联
2. 附件 / 链接
3. 科研时间轴
4. 回收站

## 任务关联

任务详情中可以建立：

- 依赖于
- 相关任务
- 后续任务

点击关联任务可以直接进入对应任务详情。

## 附件 / 链接

任务详情可以保存科研资源：

- Overleaf
- GitHub
- Google Drive
- 论文 / arXiv / DOI
- 数据 / Figure
- 网页
- 其他链接

V10 采用“链接型附件”，不把 PDF、图片、代码文件本体放进 Supabase JSON。

这样可以避免单条云端状态过大、同步缓慢或失败。

如果以后需要真正上传文件，建议单独使用 Supabase Storage，而不是把二进制文件存进现有 JSON 状态。

## 科研时间轴

左侧新增“科研时间轴”，自动汇总：

- 任务工作记录
- 科研日志
- 完成任务

支持按：

- 项目
- 类型
- 最近 30 天 / 90 天 / 一年 / 全部

进行筛选。

## 回收站

以下删除操作现在改为软删除：

- 任务
- 项目
- 科研日志
- Task Work Log

回收站支持：

- 恢复
- 永久删除
- 清空回收站

项目进入回收站时，它下面的任务和科研日志不会删除，而是暂时成为未归属内容。恢复项目时，系统会尽可能把这些内容重新挂回原项目。

工作记录恢复时，如果原任务也被删了，需要先恢复原任务。

## 搜索与导出

全局搜索现在也会搜索：

- 任务关联名称
- 科研资源名称
- 科研资源 URL

导出单个任务 Markdown 时，也会包含任务关联和科研资源。

## 数据兼容

不需要改 Supabase SQL，也不需要重新注册账号。

V9 旧数据首次加载时会自动补齐：

- `trash`
- `task.relations`
- `task.resources`
