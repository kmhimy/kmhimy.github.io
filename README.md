# 科研工作台 V11

V11 的核心目标：把 V10 的功能真正连接成一个完整的科研工作流。

## 新增

### 研究总览（Project Dashboard）

快捷键 `9`。

选择项目后集中查看：

- 任务数量与完成率
- 科研日志
- Work Log
- 科研资源
- 当前任务
- 研究总结
- 双向任务网络
- 最近科研活动

### 项目研究总结

每个项目增加：

- 研究问题
- 核心假设
- 主要结果
- 当前困难
- 下一步

### 双向任务网络

项目总览会同时显示：

- 我设置的关系
- 被其他任务关联

例如：

```text
核心推导
  ├─ 依赖于 → bright-space Hamiltonian
  └─ 后续 → numerical verification

被关联
  ← Appendix proof
```

### 项目时间轴联动

研究总览显示当前项目最近活动。点击记录可以直接进入对应任务、Work Log 或科研日志。

“查看完整时间轴”会进入 V10 的科研时间轴并自动按当前项目筛选。

## 兼容

V11 自动为旧项目补充：

```text
researchSummary
```

不需要修改 Supabase SQL。

V10 的任务关联、资源、时间轴、回收站、LaTeX、日历、外观和云同步全部保留。

如果部署后没有看到 V11，请 `Ctrl + F5` 强制刷新。


## 任务详情导出增强

任务详情现在支持 PDF、LaTeX (.tex)、Markdown (.md) 和纯文本 (.txt)。PDF 使用浏览器本地打印为 PDF，公式使用当前 KaTeX 渲染结果，不上传第三方服务。
