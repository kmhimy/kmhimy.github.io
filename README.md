# 科研工作台 V8 — 日历 / 截止日期 / 字体与风格

V8 在 V7.1 基础上新增两个长期使用功能。

## 一、日历与截止日期

左侧新增“日历”。

### 月视图
任务只要设置了 `截止日期`，就会自动出现在对应日期中。

- 科研 / 写作 / 事务 / 其他使用不同标记
- 已完成任务会淡化并加删除线
- 今天会突出显示
- 点击任务直接进入任务详情
- 点击某一天右上角 `+`，会直接建立该日期截止的任务

### 近期截止
日历右侧自动显示未来 30 天尚未完成的截止任务。

### 已逾期
超过截止日期且尚未完成的任务会单独进入“已逾期”。

已归档项目不会继续污染日常截止日期列表。

## 二、字体与界面风格

左侧新增“外观”。

### 页面风格
可选：

1. 经典学术
2. 纸张极简
3. 墨绿科研
4. 石墨简洁

### 字体
可选：

1. 中英混排
2. 现代无衬线
3. 学术宋体
4. 系统字体

### 页面密度
可选：

- 舒展
- 紧凑

所有外观设置都存入 `state.settings.appearance`，因此会继续通过 Supabase 云同步到不同设备。

## 三、数据兼容

无需重新运行 SQL。
无需修改 Supabase 表。
V7.1 的：

- 项目
- 已归档项目
- 任务
- 科研笔记
- LaTeX
- 工作记录
- 科研日志
- 云同步

全部继续兼容。
